Why it is cheaper
1
A smaller fixed prompt on every call

Copilot CLI re-sends its system prompt and tool definitions on every call. Removing 11 built-in tools that no session used in the October 18 runs cut the first call by about half.

2
Graph navigation saves calls

graphify's call graph answers "who calls X" in one compact result. On top of the lean tool set, it cut a further 15.4% (gpt-6-astra) and 9.8% (claude-opus-5.5) of raw tokens.

3
One system prompt for every session in a folder

In bring-your-own-model mode, the bridge keeps the prompt prefix identical for sessions in the same working folder. With sessions back to back, 44 of 45 gpt-6-astra sessions started from the cache; stock: 0 of 45. This saves cost only while the cache lasts (6.5 to 31 minutes in one probe).
