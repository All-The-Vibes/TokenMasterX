● Part 1 · The Math in Plain Terms · Measured vs. Estimated

Every model call re-sends a fixed prompt. TokenMaster cuts it in half.

A model has no memory between calls. On every call, Copilot CLI sends the system prompt, every tool definition, and the conversation so far. Removing 11 unused built-in tools shrinks every call, and Graphify answers call-graph questions in one lookup instead of a grep loop.

1. How GitHub Prices Every Call (Measured)From session-store.db

Copilot CLI writes the exact token counts and GitHub's charge (total_nano_aiu; 109 nano = 1 AI credit = $0.01) after every call. Prices for gpt-6.1-sol / claude-sonnet-5.5:

Token TypePrice / 1MWhat It Means
New input$2.00Input tokens not in GitHub's prompt cache
Cache write$2.50Input tokens written into the cache (1.25×)
Cache read$0.10Input tokens read from the cache (0.05×)
Output$10.00Tokens the model writes (reasoning included)
Measured Call Cost = (New × $2.00 + Write × $2.50 + Read × $0.10 + Out × $10.00) ÷ 1,000,000
Total Tokens and Cost (USD) in /tokenomics are 100% measured from GitHub's own records.
2. How /tokenomics Estimates Savings (≈)Worked Example

We do not run a hidden stock session. For each TokenMaster session, tokenomics.py estimates what stock would have spent on the same calls:

A
Every call: fixed tokens removed × cache-read price

The lean tool set removes 5,558 fixed tokens per call on 1.0.98 (9,727 on Anthropic). After call 1, stock reads its fixed prompt from cache: 5,558 × $0.10 / 1M = $0.0006.

B
First call of a session: extra cache write avoided

Your stock sessions read 0 tokens from cache on call 1. So stock would write 9,008 + 5,558 = 14,566 tokens instead of 9,008: 5,558 × ($2.50 − $0.10) / 1M = $0.0133.

Worked check (1-word session): $0.0006 + $0.0133 = $0.0139 estimated vs. $0.0154 measured ($0.0380 − $0.0226) → captures 90% of the actual difference. Across 6 A/B runs, the estimator gave 72% to 125% of the measured token saving.
Say to the room: “Total Tokens and Cost are GitHub's own numbers. Saved columns marked ≈ estimate the fixed prompt removed; they do not even count the extra calls that Graphify saves.”
● Part 2 · Architecture · Zero Changes to Normal Copilot

How tmc, Graphify, and /tokenomics fit together.

Plain copilot stays untouched. Starting Copilot with tmc wraps the launch, trims unused tools, records a prompt-free launch timestamp, and lets /tokenomics join launch windows with Copilot's SQLite store.

1. Entrypoint (PowerShell 7)

tmc → TokenMaster Launcher

~/.copilot/token-master/brainspace_copilot_bridge.py

  • Passes --excluded-tools for 11 unused built-in tools (16 → 5 tools sent).
  • Appends start/end millisecond timestamps + folder to launches.jsonl (never logs prompt text).
  • In BYOK mode only: also starts the local cache-stable prompt & v6 bridge.

Q: Measured or Estimated?

Both, clearly separated. The 45-task Django A/B (−53.4% / −51.6% tokens) is measured against real stock runs. In /tokenomics, Total Tokens and Cost (USD) are GitHub's exact per-call records; Saved ≈ is a formula estimate for your daily work where no stock twin ran.

Q: Does Dropping 11 Tools Hurt?

In our October 18 runs, 0 sessions called any of the 11 tools. In the October 19 27-task run, 1 stock session called task (subagent); TokenMaster still passed that task in 38K tokens vs. stock's 124K. Need subagents or background PowerShell? Run tmc --all-tools or plain copilot.

Q: What About CLI Versions?

Our A/B harness passed --no-auto-update, which made the WinGet launcher run its bundled 1.0.78-3 build. We caught that, disclosed it in the docs, and probed 1.0.98: the fixed prompt is smaller on 1.0.98, and the lean tool set still removes 50.1% to 53.7% of the first call.
