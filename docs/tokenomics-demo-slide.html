CACHE ARCHITECTURE

Provider prompt caches match strictly from byte zero forward. One changing byte evicts every token after it from a cheap cache read (0.05–0.10×) to an expensive cache write (1.25×).

1. Cross-session eviction (the UUID trap): Stock Copilot CLI writes Session folder: ...\.copilot\session-state\<uuid> into its system prompt. Because that UUID changes on every launch, every token serialized after it misses the cache on a new session's first call.

2. OpenAI vs. Anthropic wire order: Anthropic's /v1/messages places the tools array before system, so stock back-to-back sessions still cache the tool block (11,226 tokens on 1.0.98) and rewrite only the system prompt (6,880 tokens). OpenAI's /responses on 1.0.78-3 (and default routing on your machine) missed on the entire 13.6K–15.2K first call.

3. Intra-session eviction (why v5 failed and v6 works): In PRS-1, v5 compacted older tool outputs on later turns. Mutating Turn 2 on Turn 5 broke prefix byte-identity and raised cache-weighted cost by +61.6%. v6 shapes each tool result once when it enters the conversation and never rewrites history.

THE ARCHITECTURE

        

          Plain copilot stays untouched. Typing tmc wraps the launch, trims unused tools, logs a prompt-free launch window, and lets /tokenomics join launch windows with Copilot's SQLite store.
        

        

          Launcher (`brainspace_copilot_bridge.py`): Appends --excluded-tools for the 11 unused built-in tools and writes millisecond start/end records to ~/.copilot/token-master/launches.jsonl. In bring-your-own-model mode, it also starts the local request bridge that keeps the system prompt identical across sessions in the same folder.
        

        

          View hook (`settings.json`): Runs brainspace_posttooluse.py on whole-file view outputs, turning a 29,836-character file into a 5,175-character digest before it enters the transcript.
        

        

          Graph navigation (`navigation_mcp.py`): Exposes locate, read_symbol, and impact over Graphify's call graph and a SQLite symbol index (SCHEMA_VERSION = 4 with import ... as ... alias resolution), capped at 2,400 tokens per result.

HARD QUESTIONS

        

          Direct, evidence-backed answers for technical questions during the demo.
        

      


      

        

          Are the numbers in /tokenomics measured or estimated? Both, and the table keeps them separate. Total Tokens, Input, Output, Cache Write, Cache Read, and Cost (USD) are 100% measured from Copilot CLI's own session-store.db. The two columns marked ≈ estimate what stock Copilot would have spent on the same calls.
        

        

          Does removing eleven built-in tools hurt quality? In our October 18 runs, zero sessions called any of the eleven tools. In the pre-registered PRS-6 study on Copilot CLI 1.0.98 (176 sessions), both stock and TokenMaster scored 88/88 (29/29 on repository tasks and 15/15 on Django D01–D15 for each model). Across the earlier 90-session Django and 54-session repository runs on 1.0.78-3, TokenMaster scored 88/90 and 53/54 against stock's 90/90 and 54/54, with every miss traced to a model error.
        

        

          What if a task needs subagents or background PowerShell? Pass tmc --all-tools or run plain copilot. The launcher leaves every built-in tool in place when --all-tools is given.
        

        

          What about Copilot CLI 1.0.98 vs 1.0.78-3? The October 18–22 harnesses passed --no-auto-update, which caused the WinGet launcher to run its bundled 1.0.78-3 build. After fixing the version gate, we pre-registered and ran PRS-6 on Copilot CLI 1.0.98 (commit 19443fc, 176 sessions, 88/88 passes in both arms): on the 29-task repository benchmark, gpt-6-astra cut raw tokens by −49.5% (2,449,067 → 1,237,510, cold cost −41.5%, as-run −50.2%) and claude-opus-5.5 by −38.0% (2,672,316 → 1,655,797, cold cost −34.0%, as-run −40.1%); on the 15-task Django 5.2 replication (D01–D15), raw tokens dropped −58.5% (707,799 → 293,779, cold −53.5%, as-run −70.7%) and −53.7% (989,925 → 457,875, cold −46.0%, as-run −61.2%), lower on all 15 tasks for both models.
        

        

          When does impact miss a caller? SCHEMA_VERSION = 4 in brainspace/symbol_index.py (commit 19443fc) resolves import ... as ... and from ... import ... as ... aliases in scope (matching 56/56 answer-key callers across D01–D15, including from django.contrib.auth import login as auth_login in D13). Only dynamic dispatch, getattr, and string-based lookup remain unindexed.
        

        

          Does TokenMaster store or transmit any prompt text? No. launches.jsonl records only the start/end millisecond timestamps, the working directory path, and three booleans (lean, bridge, nav). tokenomics.py opens session-store.db read-only and makes no network calls.
        

        

          Why does /tokenomics itself cost tokens when typed as a slash command? In Copilot CLI, a personal skill injects instructions into the conversation so the model calls PowerShell and echoes the table (~16,445 tokens). Running the ! shell command printed at the bottom of the report executes tokenomics.py directly in PowerShell for zero model tokens.
