are not established.** This is a current local implementation/evidence map,
not a ranking of upstream projects or a replacement for their pinned research.

## Foundational limits remain explicit

- Shorter model input does not guarantee shorter outputs, fewer calls or the
  same answer quality.
- Exact recovery guarantees what retrieval returns when actually used, not
  that a model will recognize missing information or retrieve it within budget.
- Preserving selected structures does not prove that all task-relevant meaning
  was selected.
- Under the unchanged strict finite-sample promotion gate, equal observed
  quality cannot certify; some small plans are arithmetically impossible.
  Feasibility is checked before new nonsynthetic screening/trial spending.
- No foundation-model weights, global profiles or statistical allowances were
  changed. No policy has been promoted based on these diagnostics.

The full runtime/evaluation goal remains unfinished; the native app reports
`paused` at the October 16 handoff. These gaps are still required work, not
exclusions added to make the existing implementation look complete. See
`HANDOFF-2026-10-16.md`; earlier execution-status receipts are historical.
