01What every call carries

Every call pays for the same prompt again.

04Trim without breaking the cache

Shape each tool result once, as it arrives.

A provider's prompt cache matches from the first byte. Reading a cached token costs 0.05 to 0.1 times the input price, and writing one costs 1.25 times. Change an earlier byte and everything after it is written again.

An illustration with round numbers: one chip is 1,000 tokens, with GPT-6 Astra's price ratios. The measured case is PRS-1, where rewriting old tool output (v5) raised cache-weighted cost by 61.6% (95% CI +19.6% to +111%). A computer-checked proof shows that shaping each result once leaves earlier messages unchanged. Under default routing only the view hook shapes output. In bring-your-own-model mode a local bridge shapes grep, glob and whole-file view results and keeps the session folder out of the system prompt, so sessions in one folder share a cached prompt.

08What these numbers do not say

Read them with their limits.

Scope

  • Fifteen short lookups. Each November 1 session made two to four model calls. Long coding sessions were not measured.
  • One model on one build: GPT-6 Astra on Copilot CLI 1.0.105. PRS-6 added Claude Opus 5.5 on 1.0.98, through an evaluation relay.
  • --lean removes the same fixed prompt from every request, so it should save a smaller share of a long session. How much smaller is unmeasured.
  • With no flags, the saving comes from fewer model calls. These tasks ask the question navigation answers.
  • Two identical stock runs on the same day differed by 8.6% in raw tokens. The intervals do not include that noise.
  • Every session passed its grader in both November 1 runs, and both arms of PRS-6 passed all 88. The graders check lookups and a few edits.
  • Cold-start cost prices each first call as a cache miss. The bill itself fell 47% with --lean.

Retired or retracted

  • "Up to 58% fewer tokens." That was the best cell of PRS-6's relay run. It did not reproduce under default routing on October 27, when the lean tool set saved 47%.
  • The October 17 figures, which the repository retracted.
  • The early 72% Django pilot, which was never replicated.
  • History rewriting (v5), which raised cache-weighted cost by 61.6% in PRS-1.
  • Before the lean tool set, TokenMasterX saved cost on Copilot CLI but not reliably raw tokens.

Negative results stay published. They are in the results doc and its linked protocols.

09Try it

Install it, then run Copilot through it.

Windows PowerShell commands. The measured runs used graphify 0.9.91.

Leave out --lean and Copilot CLI keeps every built-in tool. Navigation and the view hook still work.

--lean reads the launch prompt (-p or -i), your flags and the skills and agents you have installed. An interactive session that starts without a prompt, and without a flag such as --agent, --fleet or --resume, keeps all 13 tools out, so set TOKENMASTER_KEEP_TOOLS if you need subagents or background shells mid-session.

Type /tokenomics in a session, or run tokenomics.py in a terminal for 0 model tokens, to see your measured tokens, GitHub's charges and the estimated savings.

1

Add the plugin

copilot plugin marketplace add All-The-Vibes/TokenMasterX
copilot plugin install token-master@token-master
2

Prepare the runtime, once

$plugin = "$HOME\.copilot\installed-plugins\token-master\token-master"
$runtime = "$HOME\.copilot\token-master-runtime"
uv venv --python 3.12 $runtime
& "$runtime\Scripts\python.exe" -m ensurepip
& "$runtime\Scripts\python.exe" -m pip install -r "$plugin\requirements-runtime.txt"
& "$runtime\Scripts\python.exe" -c "import tiktoken; tiktoken.get_encoding('cl100k_base')"
uv tool install graphifyy
3

Set up your repository

Start copilot in the repository and type /token-master. It indexes the repository with Graphify, then installs navigation, the view hook and /tokenomics. Approve the commands when Copilot asks.

4

Start Copilot through the launcher

& "$HOME\.copilot\token-master-runtime\Scripts\python.exe" "$HOME\.copilot\token-master\brainspace_copilot_bridge.py" --lean -- copilot
